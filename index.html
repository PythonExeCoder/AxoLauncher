Частые вопросы

Если что-то не работает — сначала посмотри здесь, потом пиши автору.

Требуется ли Java?
+
Да, для запуска Minecraft нужна установленная Java. Для 1.21.x — Java 21, для 1.16.5 — Java 11, для 1.12.2 и 1.8.9 — Java 8. Скачать можно с adoptium.net — выбери версию и нажми установить.
Куда сохраняются мои моды и ресурспаки?
+
Моды — в %APPDATA%\.minecraft\mods, ресурспаки — в resourcepacks, шейдеры — в shaderpacks. Если запускаешь .exe, все встроенные ресурсы автоматически распакуются в папку _data рядом с исполняемым файлом.
Это безопасно? Какой-то вирус?
+
Нет. AxoLauncher — открытый проект на Python с PySide6. Он использует официальный API Modrinth и публичные зеркала CurseForge. Никакой телеметрии, никаких скрытых действий — только установка модов и запуск Minecraft через minecraft-launcher-lib.
Как сменить тему оформления?
+
Открой вкладку «Настройки» → «Тема оформления» → выбери одну из семи. После выбора появится окно «Перезапустить сейчас?». Нажми «Перезапустить» — тема применится сразу.
Что если Minecraft не запускается?
+
Проверь: 1) Установлена ли нужная версия Java. 2) Есть ли достаточно ОЗУ (выдели хотя бы 4 ГБ в настройках). 3) Не блокирует ли антивирус. Если проблема остаётся — напиши автору в Telegram @IPlayWithYourFeelings с текстом ошибки из вкладки «Журнал».
Сборки Amfibia — где скачать?
+
Авторские сборки с модами, шейдерами и ресурспаками лежат на сайте pythonexecoder.github.io/cborOCHKA. В лаунчере тоже есть прямая ссылка во вкладке «Мод-паки» → «Сборки Amfibia».
